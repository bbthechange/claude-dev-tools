● Flow E

The Board — situational awareness

Its #1 job isn’t task management. In 5 seconds it answers: is anything waiting on me, and is the machine healthy? Status strip, the pinned amber Waiting lane, then the lifecycle spine.

Built as a read model over beads — local and remote are the same view.

● Cross-cut #1

The Inbox is the product

One ranked, batched queue — decisions and ideas, in and out. Amber blocks, mint is a pair session, sky is timed-fyi, slate is a digest roll-up. Never pinged twice for what could be one digest.

Your “no” must be as cheap as your “yes.”

● Flow B — the heart

Every ask is a standalone dossier

Pass 1 dedup → Pass 2 framing → Pass 3 readability → Pass 4 respondability. TL;DR, options with pre-declared consequences, blast radius, an inline-editable recommendation. The doc is the form.

Pure checkbox → deterministic & instant. Reconciler agent only for freeform.

● Flow B · step 6

A receipt, so you trust it landed

A lightweight ack so you never have to go back and check. The consequence block was applied deterministically; the runner already moved.

Confirm — so you trust it landed without checking.

● Flow A — intake

Raw thought → pipelined work

~5s of effort: one box, a project (or “let it pick”), and a tapped entry-intent preset. Each preset is a named bundle of two dials — entry stage + gate aggressiveness. An enricher agent dedups and scopes it.

You declare entry intent. The system never guesses the size.

● Flow C — capacity

One usage authority, honest state

5h ceiling, 7d budget, today’s spare line vs. actual. Per-project mode is glanceable and remotely flippable. “stopping…” renders honestly — never optimistic.

Agents downgrade their own env; only you promote to full.

● Flow G — failure

Progressive disclosure across a boundary

Glance → human-worded summary → forensic. Metadata rides the sync and is always visible. The raw stream-json never does — fetched on demand, redacted, never persisted.

Surface the silent failures loudest. Loud ones self-heal; silent ones rot.

Try it → Tap the amber card to open the dossier. Use the bottom nav to switch the two surfaces. The ＋ captures an idea. The status strip opens capacity; the red bead opens a failure.

Same read model, wider glass

“Remote” isn’t a new datastore — it’s the same beads sync rendered at desk width. The amber lane stays pinned to the top no matter the viewport.
